    Find a value

    1. Type a number the game shows, like your caps, and press First scan.
    2. Change it in the game (spend some, pick some up), type the new number and press Next scan.
    3. Repeat until a few are left, then Add the one that matches as a mod.

    My mods

    Saved mods come back every time you open the game, and Share as table saves them as a file a friend can load. To ship them with Keystone, put the file in the game's pack folder as mods.ct. Mods marked until the game closes are on values whose address changes every time the game starts: Make it last finds a way to them that survives a restart.

      In-game overlay
      
            
      A minimap, your waypoints, live stats and info cards drawn on top of the game. Set the game to borderless or windowed mode; exclusive fullscreen hides the overlay.

      Edit layout
      
          
      Ctrl+Shift+W
      Drop a waypoint where you stand
      
          
      Ctrl+Shift+G
      Teleport to the tracked waypoint
      
          
      Ctrl+Shift+F
      Find me (puts you on the minimap)

      Where you are

Height and facing are optional; facing turns the arrow on the minimap.
      
              
      
                
                
                
                
              
      
            
      
            
      
              
      
              
      
                
                
                
              
      
              
      
                Marker in the wrong spot?
                
      Stand somewhere away from the middle of the map, press Find me, then open your in-game map and type the latitude and longitude it shows for where you're standing. Keystone works out this map's scale from that, once.

            Pairing
            
      
              
              Disconnects every phone. Each one needs to scan the new code.
            
      
          
      
          
      If the address changes (your router hands out a new one), phones need to scan again. Reserving this PC's address in your router's settings avoids that.
