# Using Keystone with Fallout 4

Fallout 4 is single-player with no anti-cheat, so everything in Keystone works with it.

## Commands

Pick **Fallout 4** in the game switcher with the game running, then open **Commands**.

- **Items**: search, pick an item, choose **Give to me** or **Drop at my feet**, set the quantity, and press the button.
- **Quick commands**: god mode, no clip, caps, perk points, level, S.P.E.C.I.A.L., carry weight, run speed, time of day and more.
- **Type a command**: anything else.

Keystone switches to the game, opens the console with **~**, types the command, presses Enter and closes the console. Close the Pip-Boy, workshop and any conversation before sending a command, so it lands in the console.

If your keyboard layout puts the console on a different key, change **Console key** in **Commands → Settings**.

The console is disabled in **Survival** difficulty, so commands do nothing there.

## Mods

For values the console can't reach, load a Cheat Engine table made for your game version in **Mods**. Tables built from pointer scans (plain addresses with offsets) work best; Auto Assembler scripts are listed but need Cheat Engine itself.

## Overlay and browser

- Run the game in **borderless windowed** mode (Display settings) so the overlay and Keystone's browser can show on top of it.
- **Ctrl+Shift+B** opens the browser over the game; item pages in the Library link straight to the Fallout Wiki.
