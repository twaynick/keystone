# Using Keystone with New Vegas

Fallout: New Vegas is single-player with no anti-cheat, so everything in Keystone works with it.

## Commands

Pick **Fallout: New Vegas** on the Games screen with the game running, then open **Commands**.

- **Items**: search, pick an item, choose **Give to me** or **Drop at my feet**, set the quantity, and press the button.
- **Quick commands**: god mode, no clip, stealth, caps, levels, S.P.E.C.I.A.L., skills, Karma, XP, carry weight, Hardcore mode, time of day and more.
- **Type a command**: anything else.

Keystone switches to the game, opens the console with **~**, types the command, presses Enter and closes the console. Close the Pip-Boy and any conversation before sending a command, so it lands in the console.

If your keyboard layout puts the console on a different key, change **Console key** in **Commands → Settings**.

## Overlay and browser

New Vegas has no borderless mode. In the launcher, open **Options** and turn on **Windowed** so the overlay and Keystone's browser (**Ctrl+Shift+B**) can show on top of it.

## Snow globes

The Overlay tab has a **Snow globes** checklist with where each base-game globe is. Pick it as the checklist to show it in the overlay and on your phone. Each one sells to Mr. House for 2,000 caps.

## Mods

For values the console can't reach, load a Cheat Engine table made for your game version in **Mods**.
