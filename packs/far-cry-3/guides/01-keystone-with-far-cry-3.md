# Using Keystone with Far Cry 3

Far Cry 3 has no cheat console, so Keystone's help is the **Library**, the **overlay** and **mods**.

## Library

Every weapon, vehicle and animal the Far Cry Wiki lists for Far Cry 3, with its picture. Open any of them for its wiki page in Keystone's browser (**Ctrl+Shift+B** shows it over the game).

## Mods

Mods are for single-player only. Keystone keeps them off until you turn them on for this game and accept the warning. Far Cry 3 has a separate multiplayer mode. Use mods only in the single-player campaign, offline. Ubisoft can ban accounts for cheating in online play.

Load a Cheat Engine table made for your exact game version in **Mods**. Ubisoft updates change memory layouts, so an old table may show values as unreadable; that means the table needs updating, not that anything is wrong with the game.

## Overlay

Set **Display mode** to borderless or windowed in the game's video options so the overlay, minimap and browser can show on top. Mark where you are on the minimap with **I'm here** (Overlay tab), drop waypoints, and use timers for things like outpost resets.
