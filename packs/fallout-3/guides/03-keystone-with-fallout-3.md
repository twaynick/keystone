# Using Keystone with Fallout 3

Fallout 3 is single-player with no anti-cheat, so everything in Keystone works with it.

## Commands

Pick **Fallout 3** on the Games screen with the game running, then open **Commands**.

- **Items**: search, pick an item, choose **Give to me** or **Drop at my feet**, set the quantity, and press the button.
- **Quick commands**: god mode, no clip, caps, levels, S.P.E.C.I.A.L., skills, Karma, XP, carry weight, time of day and more.
- **Type a command**: anything else.

Keystone switches to the game, opens the console with **~**, types the command, presses Enter and closes the console. Close the Pip-Boy and any conversation before sending a command, so it lands in the console.

If your keyboard layout puts the console on a different key, change **Console key** in **Commands → Settings**.

## Overlay and browser

Fallout 3 has no borderless mode. In the Fallout Launcher, open **Options** and untick **Fullscreen** so the game runs in a window; the overlay and Keystone's browser (**Ctrl+Shift+B**) can then show on top of it.

## Bobbleheads

The Overlay tab has a **Bobbleheads** checklist with where each one is. Pick it as the checklist to show it in the overlay and on your phone.

## Mods

For values the console can't reach, load a Cheat Engine table made for your game version in **Mods**.
