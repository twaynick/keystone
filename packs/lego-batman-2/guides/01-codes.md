# Codes in LEGO Batman 2: DC Super Heroes

## Entering a code

1. Pause the game (on PC, **Enter Code** is right in the pause menu; on consoles it's under **Extras**).
2. Type the code exactly as shown.
3. If the game shows a price, buy the unlock with studs.

Red Brick extras like the stud multipliers come from finding Red Bricks in the levels; the codes here cover the ones that can be typed in.

## The codes

Keystone lists 22 codes under **Library → Codes**, each with a Copy button. Only codes that at least two separate guides agree on are included, so a typo in one guide can't send you a dud.

The **Codes entered** checklist (Overlay tab) lets you tick off characters and vehicles as you unlock them; pick it as the checklist to see it in the overlay and on your phone.

## Overlay

Run the game in **borderless** or **windowed** mode for Keystone's overlay and browser (**Ctrl+Shift+B**) to show on top.
